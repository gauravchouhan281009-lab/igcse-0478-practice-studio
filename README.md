# 0478 Exam Arena

A free, static browser-based practice studio for Cambridge IGCSE Computer Science 0478 (2026–2028).

## Run
Open `index.html` in a modern browser, or enable GitHub Pages from the repository Settings.

## Features
- Paper 1 and Paper 2 topic selection
- Randomised practice sets and timed mock-session mode
- Original Cambridge-style MCQs and short-answer prompts
- Explanations / mark-point guidance
- Local progress tracking using browser storage
- No API key, server, account or paid service required

## Syllabus basis
Cambridge IGCSE Computer Science 0478 syllabus for 2026, 2027 and 2028, including the December 2025 Version 5 update. This is an independent revision tool and is not affiliated with Cambridge International Education. All questions in this app are original practice items, not official past-paper questions.

Official syllabus: https://www.cambridgeinternational.org/Images/697167-2026-2028-syllabus.pdf
